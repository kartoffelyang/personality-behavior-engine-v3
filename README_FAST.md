# 简洁版入口

启动后打开 http://127.0.0.1:10086/fast 。原首页 `/`、原对比台 `/comparison` 和 `/flow_review` 均保留。

## 生成路径

一次模型请求输出共享动作池、共同任务方案及 ESTJ/INFP 的字段调整。程序补齐动作名称、配置原文和展示标签，复用原动作参数、依赖与任务覆盖检查，并沿用规则侧安全识别来排除其禁止的能力。快速入口仅生成计划，不连接实际执行器；车控和个人数据操作需要确认。

人格因素只来自当前 `cognitive_functions.yaml` 的主导功能行动策略（Te/Fi），不完整复刻原流程的场景策略和18维交互激活。共同方案和人格调整在同一次请求内产生，不能视作盲法、独立实验的无人格基线。程序验证配置ID、实际字段变化与动作契约，不证明人格因素与变化之间的心理因果或语义合理性。

新入口不自动生成故事、不自动重试、不缓存复用新输入的生成结果。结果、输入和实际配置引用保存在 `output/fast`；底层模型请求由原日志模块记录。任务ID保存在当前浏览器会话中，刷新可恢复已保存结果。

## 本机启动

执行 `./start-fast.sh`，使用 Python 3.12 和项目已有依赖。密钥仅保存在忽略提交的 `.env`；切勿将其写入页面、文档或版本库。

## 首轮实测，2026-11-07

同一份“雨天接孩子”输入，沿用同一网关及模型配置。旧记录：情境理解36.87秒＋最慢人格规划131.84秒，行为等待约168.71秒，不含故事。新路径：33.04秒，一次模型调用，输出1454字符，9个共同任务动作，ESTJ一处调整，INFP无调整。该比较为先后发生的单样本，受网关负载等影响，不代表稳定平均或严格质量等效。

另一个“工作受挫、准备不发送草稿”的浏览器端实测16.90秒。后续新增安全规则说明会影响提示词字数；精确配置摘要随每份结果保存。

## 人格差异展示更新

简洁版按同一动作及同一字段，直接对齐 ESTJ 与 INFP 的实际输出；用文字标记真实变化。两边做法相同时不显示差异，即使各自都相对共同方案改过，也不算两种人格之间的差异。共同任务行为和完整步骤默认折叠。

新生成的每条调整附一句 `why`，说明所引用的主导功能行动策略如何对应当前改变；服务保存为 `link_explanation`。该解释仍是模型提出的配置关联，未通过语义或心理因果验证。旧记录不重写、不自动补造解释，仍可直接对照实际行为。

检查：`node --test tests/test_fast_contrast.cjs` 验证对齐、相同结果排除、增删动作与文本标记；`python -m pytest tests/ -q` 覆盖原流程与快速生成契约。
